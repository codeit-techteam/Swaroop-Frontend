# PolyStoreX brand source of truth

Official artwork supplied by the client. Do not redraw the wordmark, recolor the X, or substitute an icon-font mark.

| File | Use |
| --- | --- |
| `polystorex-logo-original.png` | Exact supplied lockup, uncropped, black background. |
| `polystorex-logo-full.png` | Cropped lockup on black. Same pixels as `polystorex-logo-dark-bg.png`. |
| `polystorex-logo-dark-bg.png` | Splash screens and other black surfaces. |
| `polystorex-logo-transparent.png` | Full lockup for dark navy surfaces. White type is invisible on white. |
| `polystorex-logo-light-bg.png` | Same artwork on a black plate, for white headers, forms, and sidebars. |
| `polystorex-symbol.png` | Orbital symbol only. Compact nav, favicon, launcher icon. |
| `polystorex-adaptive-foreground.png` | Android adaptive foreground. Keep inside the center safe zone. |
| `polystorex-app-icon.png` | Opaque launcher icon, symbol on black. |
| `polystorex-og.png` | Social preview plate. |

Copies used by the website, customer web app, seller web app, and admin app live in each app's `public/brand/` directory. The Expo app reads `assets/brand/` plus the generated files in `assets/images/`.
